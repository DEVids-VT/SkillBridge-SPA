# Product Overview

This is a modern Single Page Application (SPA) that appears to be a platform for managing projects, companies, and candidates. The application includes features for:

- Dashboard with project management capabilities
- Company and candidate profiles with role-based access
- Project creation and management workflows
- Onboarding process for new users
- Scenario and quiz results viewing
- Multi-language support (English and Bulgarian)

The application follows a role-based access model with distinct experiences for company users and candidates. It includes an onboarding flow for new users and various specialized pages for different user journeys.

The product emphasizes user experience with smooth transitions, responsive design, and a consistent UI using a design system based on Shadcn UI components and Tailwind CSS.
